# Roast Solver (M1–M6)

A locally hostable, client-only 3-D roast heat-transfer simulator. This version includes the NumPy reference model, embedded-boundary validation, Rust/WASM solver, worker execution, and static UI described in `PROJECT_PLAN.md` through M6. It intentionally does **not** include WebGPU (M7) or photo reconstruction (M8).

> **Accuracy status:** coefficients come from literature-scale models and the calibration fixtures are synthetic. No real probe logs were supplied, so this is not empirically calibrated. Always verify food temperature with a calibrated thermometer.

## Quick start with Nix

```sh
nix develop
python -m pytest                 # Python physics/SDF/validation/golden suite
cargo test --workspace          # Rust core regressions
npm install                     # lockfile is committed
npm run build                   # Rust -> WASM, then static Vite build in dist/
npm run preview                 # http://localhost:4173
```

A reproducible static package can be built directly:

```sh
nix build
nix run nixpkgs#miniserve -- result
```

Without Nix, install Python 3.10+ with NumPy/pytest, current stable Rust, `wasm-pack`, Node 20+, and npm. Then use the same test/build commands. For Python editable installation: `python -m pip install -e '.[test]'`.

Development server: `npm run dev`. It first rebuilds WASM and then serves the app at the URL printed by Vite.

## Static hosting

Upload the **contents** of `dist/` (or the `result/` symlink from `nix build`) to any ordinary HTTPS static host: GitHub Pages, Netlify, S3, nginx, Caddy, etc. No backend, database, cookies, or API keys are needed. Serve `.wasm` as `application/wasm` (modern hosts do this by default). The build uses relative worker/WASM chunk URLs generated by Vite. A local file URL is not supported; use `npm run preview` or any local HTTP server.

## Repository map

- `roast_solver/` — authoritative readable NumPy properties, SDFs, finite-volume solver, and analytic validation helpers
- `tests/` — M1–M4 tests: Dirichlet convergence, Robin sphere anchor, exact discrete energy budget, moisture staging, and language-neutral goldens
- `crates/roast-core/` — matching Rust kernel and `wasm-bindgen` interface
- `web/src/solver.worker.js` — progressive worker runner
- `web/src/` — static UI, canvas curves, center doneness slice, pull/carryover and pasteurization outputs
- `fixtures/` — explicitly synthetic fixtures and cross-language property anchors
- `docs/PHYSICS.md` — discretization, assumptions, validation, and limitations
- `docs/CALIBRATION.md` — fixture provenance and future real-log fitting contract

## Typical reference run

```python
from roast_solver import make_geometry, simulate_roast

g = make_geometry("roast", mass_kg=1.5, n=48)
r = simulate_roast(g, initial_c=5, oven_c=180, target_c=60,
                   convection=False, covered=False, rest_minutes=30)
print(r.pull_time_s, r.peak_c, r.pasteurization_minutes[-1])
```

The pasteurization value is an equivalent-time model integral at 70°C with z=7°C. It is deliberately behind an advanced disclosure in the UI and is not a food-safety certification.
