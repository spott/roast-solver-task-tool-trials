# Validation report

The suite validates numerical invariants and analytic anchors; it does **not** validate prediction accuracy for real food. Run it with `pytest -q`, `cargo test --manifest-path rust-core/Cargo.toml`, and `npm --prefix web test`.

## M1–M4 NumPy checks

- Choi–Okos-derived bulk property envelopes and all SDF contract fields.
- Mass/volume voxelization and distinct insulated pan patch.
- Manufactured sine-mode Dirichlet box: fine-grid L2 error is at least 3.2× lower after halving `h`, consistent with the seven-point spatial stencil.
- Explicit stability guard.
- Radiation sign, wet-cell evaporation, independent depleted-cell crust transition, and pan insulation.
- Pairwise energy budget: integrated embedded net boundary flux versus numerical sensible enthalpy.
- Rest transition, core peak, and carryover reporting.
- Robin sphere roots from `1 - lambda cot(lambda) = Bi` and the exact center series.

A representative checked-in sphere case uses radius 20 mm, 45³, `h=12 W/m²K`, 20→30°C, and 900 s. With the bounded property value evaluated at 25°C:

| quantity | value |
|---|---:|
| exact center | 22.2748°C |
| embedded solver center | 22.4562°C |
| absolute error / exact center | **0.81%** |
| error / imposed 10°C span | 1.81% |
| coarea area / exact sphere area | 95.97% |
| energy residual / boundary input | 0.00018% |

Thus the plan's <1% center-temperature target is met at this practical reference resolution when “center-temperature error” has its usual relative-value meaning. The stricter span-normalized check is kept at 3% in tests. Coarea sampling is not monotonic at every integer grid size because a thin level-set band moves across voxel centers; 45³ is the locked analytic fixture, while the UI's 31³ grid is explicitly a preview. Use a resolution study for consequential cases.

The sphere and slab series are interior-model anchors analogous to the high-transfer-coefficient water-bath/Baldwin checks in the plan. Published cooking tables are not ingested as calibration observations: shape definitions, initial conditions, and table rounding are too ambiguous for a tighter claim. A high-`h` run can isolate interior diffusion, but it remains a broad plausibility comparison.

## Resolution checks

`test_dirichlet_box_converges_second_order_in_space` is the manufactured interior convergence test. `test_presets_obey_sdf_contract_and_mass_volume` bounds preset voxel volume. For production studies, run the same case at odd grid sizes (for example 33, 41, 49) and compare pull time, center curve, volume, and surface area. Do not infer uncertainty from one grid.

The current method intentionally avoids unstable tiny cut-cell volumes. Its cost is a 1.5-cell diffuse boundary and residual SDF-band aliasing. A full geometric cut-volume/face reconstruction would be a post-M6 numerical refinement, not WebGPU (M7).

## Energy convention

At each step the solver records convection, radiation, and latent terms separately. `boundary_j = convection_j + radiation_j - evaporative_j`. `sensible_j` is computed using the same lagged `rho*cp` and actual Float32 temperature increment. Interior face powers are antisymmetric. The residual test tolerance includes Float32 assignment round-off; it is not a physical loss term.

## Python ↔ Rust/WASM regression

`fixtures/wasm_golden.csv` is generated by `fixtures/generate_golden.py` from three 21³, 30-minute scenarios: roast/still/open, slab/fan/covered, and bird/fan/open. Rust integration tests compare coldest, deep probe, hottest, pasteurization, and evaporated mass.

Current native Rust differences from the Python goldens are below:

| scenario | max temperature difference | evaporation difference |
|---|---:|---:|
| roast/still/open | 0.06°C | <0.001 g |
| slab/fan/covered | 0.05°C | <0.001 g |
| bird/fan/open | 0.14°C | <0.001 g |

The locked tolerance is 0.20°C, 0.000003 equivalent minutes, and 0.002 g water. Differences come from Float32 evaluation order and a conservative fixed Rust diffusivity bound used only to select `dt`; both ports finish at the exact requested duration. The production build test additionally instantiates the raw WASM and the browser worker yields between `solver_step(80)` chunks.

## Not validated

- absolute real-oven accuracy or a particular cut/species;
- heterogeneous bone, fat, skin, cavity airflow, pan conduction, or oven cycling;
- food-safety suitability;
- empirical convection, emissivity, or moisture parameters.

Those limitations are visible in the UI and are not hidden by the synthetic fixtures.
