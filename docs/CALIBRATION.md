# Calibration fixture provenance

There are **no measured probe logs in this repository**. Nothing in this build is empirically calibrated.

- `golden_properties.json` is a language-neutral regression lock for equations in `properties.py` and Rust. It is not calibration data.
- `synthetic_calibration.json` is generated by `scripts/generate_synthetic_fixtures.py` from two deliberately small NumPy simulations. Its curves test scenario ordering and serialization only. Every file and UI surface labels this provenance.
- Analytic sphere/box checks validate numerics, not food accuracy.

Regenerate synthetic curves from the Nix shell with:

```sh
python scripts/generate_synthetic_fixtures.py
```

A future empirical workflow may ingest timestamped oven/air and leave-in-probe temperatures, reserve entire cooks as holdouts, and fit bounded convection, emissivity, and initial surface reservoir by preset. Such logs must retain instrument, placement, mass, geometry, and oven-mode metadata. Synthetic fixtures must never be mixed into that fit or described as observations.
