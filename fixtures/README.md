# Fixtures

- `wasm_golden.csv`: Python reference outputs used by `rust-core/tests/golden.rs`. Regenerate with `python fixtures/generate_golden.py`; tolerances cover only practical Float32/order differences.
- `synthetic_calibration.json`: pseudo-probe curves generated by the Python solver. Regenerate with `python fixtures/generate_synthetic_calibration.py`.

Neither file contains measured data. See `docs/CALIBRATION.md` and `docs/VALIDATION.md`.
